🚀

Blazingly Fast

Powered by Rust and Rayon multi-threading. Scans millions of files in milliseconds without breaking a sweat.

🌐

Multi-Ecosystem

Doesn't just stop at Node.js. Cleans Python venvs, Rust Cargo targets, Java Maven/Gradle builds, and Next.js/Turborepo caches.

🛡️

Safe by Default

Never deletes silently. Moves files to your OS Trash by default, or safely compresses them into .tar.gz archives you can restore later.

🖥️

Desktop GUI

Prefer pointing and clicking? Comes with a beautiful, fully-featured desktop app built with Tauri. Scan, filter, and delete with ease.

📊

Doctor & Stats

Analyze your system to find out which ecosystem is hogging the most space, and view a dashboard of your lifetime disk space savings.

⚡

Auto-Updating

Built-in self-updater and shell completions generation. Always stay on the latest version effortlessly.

Beautiful Terminal UI

Navigate and select folders to delete using an intuitive keyboard-driven interface.

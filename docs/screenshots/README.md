# Screenshots Directory

This directory contains visual documentation assets for nodewipe (README and docs website).

Screenshots to place here:
- `tui-main.png`: Interactive TUI overview with scanned artifacts list.
- `tui-dryrun.png`: TUI interactive dry-run preview mode (`[DRY-RUN ON]`).
- `cli-doctor.png`: `nodewipe doctor` output showing ecosystem disk usage.
- `cli-stats.png`: `nodewipe stats` lifetime savings dashboard.
- `gui-overview.png`: Tauri desktop app interface.
